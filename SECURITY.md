# Security policy

JavaHost runs other people's worlds, downloads mods and passes messages between players, so security reports are very welcome.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's [private vulnerability reporting](https://github.com/IbrahimMas1/javahost/security/advisories/new) instead. Include the JavaHost and Minecraft versions, what an attacker could do, and how to reproduce it.

You'll get a reply as soon as possible. Fixes ship as a normal release; serious ones as an *important* update that every player gets.

## Supported versions

Only the [latest release](https://github.com/IbrahimMas1/javahost/releases/latest) gets fixes. JavaHost updates itself, so players are normally on it.

## How JavaHost protects players

See the [Safety section of How it works](docs/HOW-IT-WORKS.md#safety): signed friend requests and status, end-to-end encrypted messages, proof that a world belongs to the friend you're joining, signed updates, hash-checked downloads, and limits against flooding.
